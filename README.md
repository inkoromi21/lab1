# Лабораторная работа № 2. Сортировки

Автор: Воробьева Семена

В этой работе я сделал WPF-приложение на C# для сравнения пяти сортировок: пузырьковой, вставками, шейкерной, быстрой и BOGO. Все выбранные алгоритмы получают один и тот же набор чисел и запускаются по очереди.

## Как запустить

Откройте проект `WpfApp1/WpfApp1.csproj` в Visual Studio на Windows и запустите его. Для сборки нужен .NET 10 SDK.

## Как пользоваться

Числа можно вписать в таблицу слева, сгенерировать или загрузить из файла `.txt`, `.csv`, `.xlsx` либо из Google Таблицы с открытым доступом. При ручном вводе подходят целые и дробные числа, например `-7,5` и `3.2`. Пустые строки и строки, в которых осталась только точка или запятая, не участвуют в сортировке. При загрузке файла или таблицы строки с буквами пропускаются.

Для генерации укажите количество чисел, минимум и максимум. За один раз можно создать до 50 000 чисел.

Затем выберите сортировки и направление: по возрастанию или по убыванию. После нажатия «Запустить сортировку» результаты появятся в таблице внизу. Там указаны время сортировки, число итераций и результат каждой сортировки. Если чисел меньше 50, программа также показывает сортировку на гистограмме. Сначала программа замеряет сортировку без анимации, потом показывает её и только после этого переходит к следующему алгоритму. Во время расчёта окно остаётся доступным, но изменить исходные данные и запустить второй расчёт нельзя.

## Что важно знать

Время измеряется через `Stopwatch`. Подготовка кадров анимации в замер не входит. «Итерация» у разных алгоритмов означает разный шаг. Например, у пузырьковой сортировки это проход по массиву, а у шейкерной — проход в обе стороны. Если массив уже отсортирован, обе сортировки покажут одну итерацию и остановятся. Сравнивать скорость только по числу итераций нельзя. На маленьком наборе время может заметно меняться от запуска к запуску, поэтому программа называет алгоритм, который был быстрее именно в этом запуске.

BOGO-сортировка работает случайным перемешиванием. Для неё есть лимит итераций, и её можно запускать только на наборе не больше 11 чисел. Если лимит закончился раньше, чем числа упорядочились, в таблице будет написано, что сортировка остановлена.

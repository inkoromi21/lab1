# Лабораторная работа №2

## Цель

Сравнить пять алгоритмов сортировки: пузырьковую сортировку, сортировку вставками, шейкерную, быструю и BOGO-сортировку.

## Входные данные

Программа принимает дробные и отрицательные числа из таблицы, случайно сгенерированного набора, CSV/TXT-файла, Excel-файла с числовыми ячейками или общедоступной Google Таблицы.

## Результат

Программа сортирует выбранные алгоритмы по возрастанию или убыванию, измеряет время и количество итераций, показывает процесс сортировки на гистограмме и выводит таблицу результатов.

## Примечание

Для BOGO-сортировки задаётся лимит итераций. Она доступна только для 11 чисел или меньше, потому что намеренно работает очень медленно.
